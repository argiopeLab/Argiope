Ajuda e Tutorial

Guia para recursos e conceitos técnicos do Argiope

Aprenda a usar o Argiope com nossa playlist de tutoriais em vídeo.

Introdução

Argiope é um pacote de desktop para análise e padronização de imagens. Ferramentas assistidas por IA são integradas em ambos os módulos para oferecer suporte especializado.

Analisar Imagens fornece ferramentas para segmentação de imagens, detecção de objetos, classificação de imagens e extração de dados de imagens em imagens RGB, multiespectrais e hyperespectrais.

Padronizar imagens executa a calibração da imagem, convertendo a saída bruta da câmera em valores proporcionais às verdadeiras propriedades ópticas da cena, para que as cores sejam precisas e comparáveis.

Página inicial

  • Analisar imagens: Inicia o módulo de análise.
  • Padronizar imagens: Inicia o módulo de padronização.
  • Entrar/Sair: Encerra a sessão e retorna à página de login.

Acesso e contas

A página Conectar-se gerencia a autenticação do usuário e a criação de conta local. As configurações do usuário e os modelos de IA são armazenados por conta. Alguns modelos compartilhados podem ser acessados por todos os usuários.

Fazendo login

  1. Digite seu nome de usuário. Um menu suspenso lista contas criadas anteriormente para seleção rápida.
  2. Digite sua senha. Use Mostrar para alternar a visibilidade e evitar erros de digitação.
  3. Clique em Conectar-se para iniciar uma sessão.

Criando e excluindo usuários

Selecione Criar usuário para abrir um modal com campos para nome de usuário e senha. Você pode deixar o campo de senha vazio. A nova conta é salva localmente e aparece na lista de sugestões.

Atualizando senhas

Clique em Alterar senha para abrir um modal pré-preenchido com o nome de usuário logado. Forneça a senha antiga, digite e confirme a nova e clique em Atualizar senha. A alteração é salva imediatamente.

Acesso de convidado

Argiope abre automaticamente como convidado. Use Acessar como convidado para explorar recursos sem credenciais. As sessões de convidados também persistem os dados do usuário, incluindo modelos e anotações.

Padronizando Imagens

Este procedimento de várias etapas converte fotografias RAW em arquivos com correção de cor usando um padrão de referência.

Somente formatos de imagem RAW são aceitos como entrada. A maioria dos fornecedores de câmeras é compatível, incluindo Canon, Nikon, Sony, Samsung, Panasonic e Olympus. Como os arquivos RAW preservam os dados brutos do sensor, oferecem maior flexibilidade para processamento.

É necessário um padrão de referência com valores de refletância conhecidos (por exemplo, X-Rite ColorChecker Passport ou Labsphere Diffuse Reflectance Standards). O padrão é usado para ajustar a relação entre os valores de pixel e os valores de refletância verdadeiros.

As imagens calibradas são salvas como arquivos TIFF ou ENVI. As imagens ENVI são compostas por dois arquivos (.hdr e .dat).

As imagens não passam por correções de distorção de barril que podem introduzir pequenas distorções dependendo do tipo de lente.

Configurações de calibração

Você pode tratar imagens de forma independente (modo de processamento Separate images) ou como grupos (modo de processamento Stacking images). O agrupamento é pretendido para imagens de múltiplos canais que devem ser alinhadas e processadas juntas.

Adicionando e organizando arquivos
  • Adicionar arquivos ou Adicionar pasta para importar do disco.
  • Os itens importados aparecem como miniaturas. Você pode arrastar e soltar os cartões para reordená-los.
  • Importante: Se os arquivos adicionados estiverem armazenados em uma fonte externa que requer conexão com a Internet, certifique-se de que sua conexão esteja estável. Uma conexão instável pode afetar o processamento.

1) Se você escolheu Empilhar imagens, três abas estão disponíveis: Canais, Alinhamento e Calibração.

Guia de Canais

A estrutura de Empilhamento de imagens aparece como grupos de imagens. Cada linha representa um grupo a ser tratado como uma imagem multiespectral. As linhas são alinhadas para que cada imagem dentro do grupo corresponda aos mesmos objetos espaciais.

  • Dentro de um grupo, você pode reordenar (arrastar e soltar) ou remover imagens (ícone de lixeira).
  • Entre grupos, você pode reordenar (arrastar e soltar) ou remover grupos (ícone de lixeira).
  • Você pode criar um novo grupo.
  • Use o ícone de configurações na parte inferior para escolher se deseja usar todos os canais (R, G, B) ou deixar o Argiope selecionar automaticamente um único melhor canal.
  • Especifique CWL (comprimento de onda central) e FWHM (largura total na metade do máximo) para cada canal. A entrada aceita números (por exemplo, 450) ou rótulos (por exemplo, UV). Embora não seja obrigatório, é fortemente recomendado para análises espectrais precisas.
Guia de Alinhamento

Alinha as imagens umas em relação às outras para que todos os canais espectrais se sobreponham corretamente para composição multiespectral. Existem três opções: Correspondência de recursos + homografia, Correção de fase ou Manual. O alinhamento automático funciona na maioria dos casos.

Guia de Calibração
  • Padrões de cores
    • Selecione ou adicione o padrão de cores usado em suas imagens. Esses valores conduzem a conversão de intensidades de pixel para refletância calibrada. Você pode adicionar, remover ou editar padrões conforme necessário.
  • Coordenadas do padrão de cores
    • Argiope precisa das localizações das amostras de referência para extrair intensidades. Opções:
      • Indicar localizações em cada imagem (totalmente manual);
      • Indique localizações na primeira imagem de cada grupo (outras herdam após alinhamento);
      • Utilize a primeira imagem do primeiro grupo como referência (os demais grupos herdam o mesmo layout);
      • Use um detector assistido por IA. Clique em Modelos de IA para configurar.
  • Botão Modelo de IA
    • Adicione um modelo treinado para detectar automaticamente o padrão de cores.
    • Modelos de IA para coordenadas do padrão de cores

    Você pode usar um modelo treinado para detectar automaticamente padrões de referência. Argiope integra-se com o aplicativo da web Roboflow (https://roboflow.com). Roboflow oferece um fluxo de trabalho fácil de usar para modelos de treinamento. O modelo deve localizar cada amostra de padrão de cor individual usada para calibração.

    Clique em Modelos de IA para configurar:

    • URL: forneça o caminho do modelo Roboflow (por exemplo, colorchecker-segmentation/3).
    • Chave API: necessária para inferência Roboflow. Sua chave API é pessoal e confidencial (disponível em sua conta Roboflow).
    • Limite de detecção: as detecções abaixo desta confiança são descartadas.
    • Tampão (%): deslocamento da borda aplicado aos polígonos detectados. Os valores positivos dilatam para fora; valores negativos sofrem erosão para dentro. A porcentagem é aplicada por borda.

2) Se você escolheu Imagens separadas, duas abas estão disponíveis: Canais e Calibração.

Guia de Canais

As imagens aparecem como miniaturas. Os canais R, G e B de cada imagem serão calibrados. Use os controles de seta ou arraste e solte miniaturas para alterar a ordem das imagens (útil quando a primeira imagem serve como referência).

Guia de Calibração

As mesmas opções acima se aplicam.

Opções de exportação

Selecione o tipo de arquivo (TIF ou ENVI) e o tipo de dados (8 bits ou 32 bits). Um arquivo de 8 bits é menor (0 a 255 números inteiros), mas não pode armazenar decimais ou valores negativos. Um arquivo de 32 bits oferece maior precisão e intervalo de valores.

Processamento e Progresso

Clique em Processar para iniciar a padronização. Um modal exibe texto de status e uma barra de progresso ao vivo. Você pode abortar a qualquer momento. Quando concluído, a página de Resultados mostra os arquivos processados e estatísticas de calibração.

Revise os resultados

  • Um alerta de erro lista quaisquer falhas de processamento.
  • Uma galeria exibe cada imagem com seu relatório.
  • Um gráfico mostra a regressão usada para converter valores de pixels em valores padronizados, juntamente com equações e R2.
  • Use Refazer a padronização da imagem para ajustar parâmetros ou Concluir para retornar à página inicial.

Detalhes técnicos sobre o fluxo de trabalho de padronização

O algoritmo Argiope para padronização de imagens passa pelas seguintes etapas:

  1. Abra a primeira imagem RAW.
  2. Usando as coordenadas do padrão de cores, calcule a intensidade média de pixel para cada amostra.
  3. Combine essas medidas com os valores de referência definidos na seção Padrões de cores.
  4. Ajuste um modelo linear de mínimos quadrados com valores de referência do padrão de cores como a resposta e intensidades médias de pixels como o preditor. Ajuste os canais R, G e B separadamente.
  5. Aplique cada modelo para converter cada pixel da intensidade original em valor calibrado.
  6. Se Melhor canal estiver selecionado, escolha o canal de acordo com:
    1. Modelo R2 > 0,97;
    2. Maior valor medido, intensidade não saturada (uma amostra é não saturada se sua intensidade máxima medida < 65.535);
    3. Se nem (1) nem (2) forem atendidos, selecione o canal com o R2 mais alto.
  7. Se estiver gerando uma imagem multiespectral (diretórios), repita as etapas para cada imagem do grupo.
    1. Se selecionado, aplique o alinhamento registrando a imagem atual na primeira imagem (antes do cálculo da intensidade).
  8. Se a primeira imagem/grupo for definida como referência, aplique o(s) modelo(s) às imagens restantes; caso contrário, repita as etapas para cada imagem/grupo.
  9. Armazene os coeficientes gerados e as estatísticas de ajuste como metadados para posterior revisão e reprodutibilidade.

*As imagens RAW são processadas conforme fornecidas pela câmera. A correção de distorção da lente não é aplicada, portanto podem ocorrer pequenas diferenças geométricas dependendo da lente utilizada.

Analisar Imagens

Importando Imagens

Abra a página Analisar Imagens e clique em Importar imagens. Se um arquivo de anotação gerado por Argiope estiver na mesma pasta, polígonos, tags de imagem e tags de polígono serão carregados automaticamente.

Importante: Se os arquivos adicionados estiverem armazenados em uma fonte externa que requer conexão com a Internet, certifique-se de que sua conexão esteja estável. Uma conexão instável pode afetar o desempenho.

Gerenciando a Galeria de Objetos

Cada arquivo importado aparece como um cartão de arquivo com miniatura, título, ícone de remoção e caixa de seleção.

  • Selecionar tudo e Limpar seleção alternam seleções em massa.
  • A remoção de um cartão exclui a imagem da sessão.
  • Clicar em outro lugar em um cartão abre a imagem.

Visualizando objetos e recursos de edição

Abrir um cartão de arquivo inicia um modal de tela inteira com abas para interação de imagens e resumos de análise.

Ferramentas da barra de ferramentas

A barra de ferramentas flutuante acima da tela inclui:

  • Redefinir visualização: Restaura o zoom e a posição originais.
  • Seletor de recursos: Ativa o modo de seleção para polígonos existentes.
  • Ferramenta SAM: Usa o modelo Segment Anything para segmentação automática.
    • Coloque dois pontos dentro do objeto de interesse; Argiope irá detectá-lo e segmentá-lo. Um polígono é gerado e adicionado à lista de Objetos.
  • Desenho de polígono: Rastreie manualmente regiões de interesse.
  • Desenhar linha: Rastreie manualmente regiões de interesse.
  • Desfazer e Refazer: Desfazem e refazem as últimas 10 alterações aplicadas aos polígonos.
  • Ampliar, Diminuir zoom e Deslocar: Ajustem a janela de visualização. Manter Shift pressionado é um atalho para Deslocar.
  • Importar arquivo de recurso: Adicione anotações diretamente do visualizador. Importe um JSON no Formato COCO ou um arquivo ROI ImageJ.
  • Exportar arquivo de recurso: Exporte um JSON no Formato COCO ou um arquivo ROI ImageJ (https://imagej.net/ij/).
  • Selecionar o modelo: Escolha qual modelo de IA aplicar; Gerar recursos (IA) executa-o na imagem atual.
Lista de objetos e tags

O painel lateral lista todos os objetos. Você pode adicionar tags para classificar a imagem ou objetos individuais.

Modelos de IA e geração de objetos

Use modelos integrados ou conecte serviços externos para gerar recursos como polígonos (segmentação), caixas delimitadoras (detecção) ou rótulos em nível de imagem (classificação).

Tipos de modelos suportados
  • Segmentação Zero-shot: Detecta e segmenta objetos a partir de uma ou mais palavras descritivas. Executa localmente.
  • Detecção Zero-shot: Igual ao acima, mas retorna caixas delimitadoras. Executa localmente.
  • Segmentação Roboflow: Usa um modelo treinado em Roboflow (https://roboflow.com) por meio de seus servidores de inferência. Roboflow é um aplicativo web para gerenciar datasets e treinar modelos customizados.
  • Classificação Roboflow: Utiliza um modelo Roboflow para classificação de imagens; retorna rótulos adicionados às tags de imagem.
  • Classificação Gemini: Usa o modelo Google Gemini para classificação de imagens com base em um prompt; retorna rótulos adicionados às tags de imagem.
Modelos de IA: como adicionar modelos
  • Clique em Modelos de IA. Para adicionar um modelo, digite um nome e selecione o tipo de modelo:
    • Segmentação Zero-shot:
      • Lista de objetos: Adicione palavras-chave que descrevem alvos (separadas por vírgula), por exemplo, borboleta, pequeno quadrado verde, grande círculo. Experimente variações para melhorar os resultados.
      • Limite de detecção: Limite de confiança por objeto (separado por vírgula). Limites muito baixos (por exemplo, 0,001%) podem ajudar durante a exploração.
      • Máx. número de recursos: Máximo de objetos por tipo a serem retidos (separados por vírgula). Mantém os resultados de maior confiança.
      • Tampão (%): Deslocamento de borda aplicado a polígonos. Os valores positivos dilatam para fora; valores negativos sofrem erosão para dentro. A porcentagem é aplicada por borda.
    • Detecção Zero-shot: Igual ao acima, mas retorna caixas delimitadoras.
    • Segmentação Roboflow:
      • URL: Forneça o endereço do modelo Roboflow (por exemplo, colorchecker-segmentation/3).
      • Chave API: Necessária para inferência Roboflow (mantida pessoal e confidencial). Para localizar sua chave API, acesse sua conta de usuário no Roboflow WebApp.
      • Limite de detecção (%): Confiança mínima. Somente detecções com valores de confiança acima do limite serão mantidas.
      • Máx. número de recursos: Máximo de objetos por imagem.
      • Tampão (%): Deslocamento de borda aplicado a polígonos. Os valores positivos dilatam para fora; valores negativos sofrem erosão para dentro. A porcentagem é aplicada por borda.
    • Classificação Roboflow:
      • URL e Chave API como acima.
    • Classificação Gemini:
      • Chave API: Necessária para inferência Gemini (mantida pessoal e confidencial). Para localizar sua chave API, acesse sua conta de usuário no Google AI for Developers.
      • Modelo: Selecione o modelo Gemini.
      • Prompt: Digite um prompt para o modelo Gemini. Por exemplo: "Leia o rótulo desta imagem e retorne seu conteúdo."

Listas de imagens

Uma Lista de imagens é um arquivo .json salvo que registra os caminhos de todas as imagens carregadas em uma sessão. Abrir uma lista restaura o conjunto completo de imagens com todas as anotações.

Quando uma lista é aberta, Argiope carrega automaticamente o arquivo COCO complementar de cada imagem e restaura todos os recursos.

Use o botão Listas de imagens na barra superior para abrir, salvar ou fechar uma lista. Um ponto âmbar próximo ao nome da lista indica alterações não salvas.

Executando Análise

Selecione uma ou mais imagens e pressione Analisar seleção. Os dados são extraídos para cada objeto em cada imagem e armazenados em um arquivo de planilha delimitado por tabulações.

Colunas exportadas por padrão:

  • file_name, image_path: Informações do arquivo de origem e tags anexadas à imagem.
  • object_name, object_id: Rótulo do objeto e ID exclusivo do objeto em uma imagem.
  • object_tags: Tags no nível do objeto (classificação do objeto).
  • object_coordinates: Coordenadas x e y dos vértices do objeto.
  • object_N_Pixels: Número de pixels dentro da máscara. Pode ser usado para calcular o tamanho real de objetos com base em uma escala conhecida.
  • object_hasInf, object_hasNA: Sinalizadores para valores infinitos ou NaN após o mascaramento.
  • área, area_unit, comprimento, length_unit: Tamanhos calculados com base na escala de referência fornecida pelo usuário.

Imagens poligonais

Após a análise, uma pasta argiope_data é criada no mesmo diretório onde está a imagem. Dentro desta pasta são criadas pastas adicionais com nomes de imagens onde é salvo um arquivo de imagem de cada polígono.

Os nomes dos arquivos de imagem são salvos com uma estrutura nome_objeto + id_objeto para que os usuários possam consultá-los facilmente no arquivo de planilha.

Além disso, imagens poligonais podem ser abertas em outros softwares (por exemplo, ImageJ, Adobe Photoshop, R, Python) para extração de dados adicionais no nível do polígono.

Análises

Use Análises para anexar estatísticas à tabela exportada. Todas as saídas são gravadas por objeto; os resultados que criam imagens também anexam visualizações dentro da pasta de polígonos.

Estatísticas Básicas
  • Estatísticas de valores brutos: object_overall_max/min/mean/std/median/mad* e média std**. Estatísticas resumidas de todos os valores de pixel mesclados entre canais no objeto.
  • Estatísticas de raiz quadrada transformada e Estatísticas de logaritmo natural transformado (ln+1): As mesmas estatísticas após transformar os valores dos pixels para melhorar a normalidade.
  • Estimativa de densidade do kernel: Estimativa do modo baseado em KDE (ponto de maior densidade) para o objeto (coluna 'object_multimax'). Estes representam a combinação mais comum de valores de pixel.
  • Estatísticas em nível de canal:
    • channel_CWL e channel_FWHM: Comprimento de onda central e largura total na metade do máximo dos metadados da imagem; um par por canal.
    • channel_mean, channel_std, channel_median, channel_mad, channel_max, channel_min: Estatísticas por canal espectral.
    • channel_relative_intensity: Intensidade relativa média do canal (valor do canal dividido pela soma do canal por pixel e, em seguida, calculada a média de todos os pixels). Por exemplo, Rrelativo, Grelativo e Brelativo são calculados em média através do polígono.
    • Cada linha da planilha representa um canal espectral dentro de um polígono. As métricas que pertencem a todo o polígono (número de pixels, média geral, etc.) são repetidas para cada linha.

*O desvio absoluto mediano (mad) é uma medida de variabilidade calculada como 1,4826 × median(abs(xi - mediana(x)))

**object_overall_mean_std, object_ln1_overall_mean_std, object_sqrt_overall_mean_std: O desvio padrão médio dos canais no nível do pixel. Por exemplo, em uma imagem RGB, isso será calculado a partir dos desvios padrão de R, G e B.

Descritores de forma

Selecione apenas os descritores de forma que deseja exportar. Essas métricas são calculadas a partir da máscara poligonal, independentemente dos valores de intensidade de pixel.

  • Circularidade: Exporta object_Circ. Calculado como 4π×área/perímetro². Valores mais próximos de 1 indicam formato mais circular; valores mais próximos de 0 indicam formatos mais alongados.
  • Razão de aspecto: Exporta object_AR. Calculado como major_axis/minor_axis a partir dos eixos da elipse ajustados.
  • Arredondamento: Exporta object_Round. Calculado como 4×área/(π×major_axis²).
  • Solidez: Exporta object_Solidity. Calculado como área/área_convexa.
  • Centróide: Exporta object_X e object_Y. Estas são as coordenadas x e y médias de todos os pixels dentro da máscara poligonal.
  • Perímetro: Exporta object_Perim. Este é o perímetro da máscara poligonal em unidades de pixel.
  • Caixa delimitadora: Exporta object_BX, object_BY, object_Width e object_Height. Eles descrevem o menor retângulo alinhado aos eixos que contém o objeto.
Análise de Componentes Principais (PCA)
  • Calcula autovalores e autovetores a partir dos pixels mascarados (requer pelo menos dois canais e pixels suficientes).
  • Exporta autovalores PC1 e PC2 (object_PC1, object_PC2) e a soma dos autovalores (object_PC_sum).
  • Um arquivo JSON com todos os autovalores/autovetores, covariância e contagem de amostras é salvo na pasta de imagens dentro da pasta do polígono.
Índice de Moran em PCA
  • Mede a autocorrelação espacial em rasters PC1 e PC2 derivados do polígono.
  • Exporta moran_I_PC1 e moran_I_PC2; valores positivos mais altos indicam agrupamento, valores negativos indicam dispersão.
Agrupamento K-Means
  • Segmenta os pixels dentro do polígono em clusters rígidos. O modo manual usa o número de agrupamentos escolhido; o modo automático testa até o máximo de clusters usando pontuação de silhueta.
  • Exporta rótulos de cluster (kmeans_labels_img), kmeans_n_clusters, centros de cluster, proporções e kmeans_patch_diversity_relative (diversidade de cores). A diversidade de cores é calculada como (1/soma(proporção_cluster²))/número_de_clusters.
  • A melhor contagem de clusters no modo automático é aquela com a pontuação de silhueta mais alta, equilibrando compacidade e separação.
  • Um arquivo JSON é salvo na pasta de imagens dentro da pasta do polígono com detalhes da análise.
  • Um arquivo de imagem com clusters e centros de cluster é salvo na pasta de imagens dentro da pasta do polígono.
Modelo de Mistura Gaussiana (GMM)
  • Ajusta um modelo de mistura com covariância diagonal. O modo manual usa a contagem de componentes fornecida; o modo automático seleciona a melhor até o máximo de componentes usando BIC.
  • Exporta gmm_labels_img, gmm_n_clusters, médias/pesos do cluster e gmm_patch_diversity_relative. A diversidade de cores é calculada como (1/soma(proporção_cluster²))/número_de_clusters.
  • Observação: gmm_labels_img pode exibir menos clusters visíveis do que os componentes do modelo se alguns componentes não receberem pixels.
  • BIC escolhe o modelo mais simples que explica os dados.
  • Um arquivo JSON é salvo na pasta de imagens dentro da pasta do polígono com detalhes da análise.
  • Um arquivo de imagem com clusters e centros de cluster é salvo na pasta de imagens dentro da pasta do polígono.
Fórmulas definidas pelo usuário
  • Crie métricas personalizadas por polígono no nível do pixel. Para cada fórmula, forneça um nome e uma expressão; os resultados são exportados como User_{name}.
  • Clique em Ler canais para detectar os nomes dos canais das imagens selecionadas. Se nenhuma imagem for selecionada, ele lê os nomes dos canais de todas as imagens.
  • Consulte os canais pelos seus rótulos (por exemplo, R, band1) ou com band("label"). Ajudantes matemáticos/estatísticos suportados incluem mean, median, std, min, max, sum, count, símbolos aritméticos básicos (+ - * / ^) e comparações (> < >= <= == !=).
  • Exemplo: count(R > 0.5) conta pixels dentro do polígono onde R é maior que 0.5.
  • Exemplo: (R - G) / (R + G) calcula uma diferença normalizada no nível do pixel e depois calcula a média entre os pixels dentro do polígono.

Limitações conhecidas

  • Devido às limitações do sistema, caminhos muito longos podem causar problemas no acesso a arquivos ou no salvamento de resultados.
  • Argiope depende de rawpy (LibRaw) para decodificar arquivos NEF da Nikon, portanto só pode ler NEFs compatíveis com LibRaw. Algumas variantes NEF mais recentes da Nikon (principalmente certificadas recentemente) podem não ser suportadas.
  • As imagens têm tamanho máximo de 178.956.970 pixels (~180 megapixels). Imagens maiores não serão processadas.

Suporte

Para obter assistência ou relatar problemas, entre em contato com a equipe de desenvolvimento do Argiope: https://github.com/argiopeLab/Argiope/issues/

Glossário

CWL (Comprimento de Onda Central)
O comprimento de onda central de um canal espectral. Valores CWL precisos são necessários para interpretar os dados de cada canal corretamente.
FWHM (Largura Total na Metade do Máximo)
A largura de um canal espectral medida na metade de sua intensidade de pico. Juntamente com CWL, define a faixa de sensibilidade de cada canal.
Padrão de cores
Um gráfico de referência com valores de refletância conhecidos. Incluí-lo nas fotografias permite que o Argiope padronize os valores dos pixels, garantindo que as medições sejam comparáveis entre diferentes sessões e câmeras.
Modelo de calibração
O modelo estatístico (normalmente um modelo linear geral) que mapeia os valores de intensidade da câmera para valores de refletância padronizados.
Segmentação de imagens
Um processo de visão computacional que particiona uma imagem em regiões ou objetos distintos, agrupando pixels com características semelhantes.
Classificação de imagens
Uma tarefa de visão computacional que atribui um rótulo ou categoria a uma imagem inteira com base em seu conteúdo visual. Os modelos aprendem padrões e recursos e depois categorizam as imagens.
